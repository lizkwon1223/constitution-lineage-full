# 제헌헌법 조문 계보 지도 v5

v4 화면에 저장된 completion 결과를 추가한 독립 버전. 기존 v4의 장별 요약 설명도 요청에 따라 간결하게 수정했으며, 수정 전 v4는 `outputs/site_v4_review/v4_before_v5_completion_20260925.zip`에 보존.

## 화면

- 기존 전체 지도, 유진오 초고 중심, 조문별 분석 유지.
- **Completion 해석 → 제헌헌법 원문**: 내용·조문 번호와 장으로 검색. 원문 아래 한글 문언을 읽고 조문을 선택해 AI 해석 결과로 이동. 원문은 completion 입력에서 추출.
- 조문별 해석 제목: AI의 조문 해석. 문헌별 집계 B/C 막대에 단계 표시 추가.
- **Completion 해석 → 조문별 해석**: 103개 조문별 후보 합집합, 두 방식의 3회 선택 결과, 회차별 판단 이유·인용·원문. `#completion-74`처럼 조문 주소로 바로 이동.
- **문헌별 선택**: 문헌군별 선택된 제헌헌법 조문 수. 3회 평균 또는 회차별 수. 동일 문헌군의 여러 후보가 선택돼도 대상 조문은 한 번만 집계. 후보 제시 조문 수 병기. 막대 선택 시 조문 목록.
- **후보 구성**: RRF 상위 7개와 14군별 RRF 1위의 차이, 입력·반복·해설 범위.
- **사후 검토**는 모델 원응답과 별도 표시. 14군 대표 103조, RRF 상위 7개 11조의 기존 해설 수록.

- **참조메모 원본 이미지**: 개별 메모 카드의 미리보기를 누르면 확대 창으로 열림. 원본 크기·화면 맞춤 전환, 스크롤, 닫기·Esc 지원. 24건을 기존 crop 23장에 연결(N20a/N20b는 같은 이미지). 조문 상세의 참조메모에서도 동일하게 열림.

## 데이터와 단위

- Completion 후보 검색 범위: 19개 판본, 14개 문헌군, 1,563개 조문. 유진오 초고와 행정연구위원회안을 포함한 기존 지도 후보 범위와 다름.
- RRF 상위 7개: 전체 RRF 1–7위. 14군 대표: 14개 군마다 1위 한 조문. 두 방식 모두 코사인 하한 없음.
- 같은 입력으로 각각 3회. 103조 × 3회 × 2방식 = 618개 원응답. 저장된 모델명 `claude-opus-5`.
- 복수 선택 결과이며 1위 문헌 집계가 아님. 미제시, 명시적 비선택, 개별 검토 누락을 구분. 후보 검토 누락은 RRF 4건, 14군 15건.
- 이번 작업에서 새 모델 호출·재분석 없음. 원자료, 모델의 선택, 사후 해설 내용은 수정하지 않음.

원자료: 작업 폴더의 `북한추가진행/completion_103_rrf_top7_rep3_v1`, `북한추가진행/completion_103_family14_rep3_v1`.

`completion-data/`의 입력·구조화된 원응답·사후 해설 JSON은 원본 파일의 바이트 복사. `article-N.js`는 화면용 캐시. API 전송 기록·인증정보는 사이트에 포함하지 않음.

## 열기·검증

```text
python -m http.server 8768 --bind 127.0.0.1 --directory repository/site_full_v5
node repository/scripts/check_site_v5.cjs
```

오프라인 자료 내보내기: `repository/scripts/10_export_completion_v5.py`.
